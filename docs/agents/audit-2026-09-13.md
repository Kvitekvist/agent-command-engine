  chunk still triggers a size warning because it includes offline worker bodies;
  initial chunk reduction is not a reduction of the entire application payload.

  navigation/new windows, renderer-reload reconnection and child-process stop
  passed on Windows. node-pty printed an AttachConsole teardown error even though
  the child process exited; this warning remains a Windows runtime observation.
- Windows diagnostic package under `releases/audit-20260914/Portable-ACE` passed
  packaged tokscale 4.13.0, real PTY startup/I/O using the packaged executable and
  archived host, and renderer/worker loading from app.asar. It is unsigned and
  was not tagged, published, installed globally or used to replace the running app.
- An isolated npm ci with the exact manifests and postinstall passed with zero
  advisories. In-place ci met a live Vite/Electron file lock; after permission,
  only Vite was stopped. Missing dependencies were restored from the clean
  installation without overwriting locked files. Vite was restarted hidden and
  returned HTTP 200 on port 5173; tests and packaged runtime checks passed again.
  The earlier ACE process was no longer present afterward; no stop was issued
  to ACE or its PTY host, and application relaunch was left to the user.
- No macOS machine or clean managed-machine signature verification was used.
  Repository secret-name lookup returned an empty list; organization-level
  signing availability was not established. Never put private keys in this ledger.

## Boundaries and remaining work

The project path guard is not a sandbox for programs explicitly run from the
project. Static link escapes are covered, but hostile concurrent symlink swaps
and external writes during the final check/rename interval need OS-level
primitives for a stronger guarantee. Terminal replay is bounded to 256K
characters, not a persistent full emulator snapshot. App quit intentionally ends
PTYs; renderer detachment and macOS window close do not.

Complete the still-named verification checks before closing their tickets.
Do not mark this ledger's entire set complete from unit tests alone.
